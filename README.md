# Armenian Bible LockScreen (Աստվածաշունչ Կողպման Էկրանին) ✝️

Красивое, минималистичное и полностью функциональное iOS-приложение со встроенным виджетом для экрана блокировки (**Lock Screen Widget**). Приложение отображает вдохновляющие стихи из Библии на армянском языке.

Интерфейс приложения, виджета и инструкции полностью локализованы на армянский язык.

## 🌟 Особенности

*   **Локскрин Виджет**: Реализован в формате `accessoryRectangular` для экрана блокировки iOS 16+.
*   **Автоматическое обновление**: Виджет автоматически обновляет стих на экране блокировки каждый час с помощью `TimelineProvider` (автономный цикл на 5 часов вперед).
*   **Мгновенная синхронизация (App Group)**: При нажатии кнопки «Պատահական տող» (Случайный стих) в приложении виджет мгновенно обновляется на экране блокировки благодаря механизму `WidgetCenter` и общей памяти `UserDefaults(suiteName: "group.com.samvel.ArmenianBible")`.
*   **Премиальный темный интерфейс**: Выполнен в глубоких темных тонах с неоновой подсветкой, геометрической сеткой точек и плавной пружинной анимацией смены стихов.
*   **Тактильная отдача (Haptics)**: Интегрирован мягкий физический отклик при генерации нового стиха.

## 🛠 Инструкция по сборке и настройке App Groups

Для полноценной работы виджета и приложения требуется общая группа приложений (App Groups).

1.  **Сгенерируйте Xcode-проект**:
    Выполните команду в корневой папке проекта:
    ```bash
    xcodegen generate
    ```

2.  **Откройте проект в Xcode**:
    ```bash
    open ArmenianBible.xcodeproj
    ```

3.  **Настройте App Groups (Важно!)**:
    Чтобы данные синхронизировались между приложением и виджетом, Xcode должен настроить контейнер App Group:
    *   Выберите корневой элемент проекта **ArmenianBible** на левой панели.
    *   Для таргета **ArmenianBible** перейдите во вкладку **Signing & Capabilities**.
    *   Нажмите **+ Capability** в левом верхнем углу и выберите **App Groups**.
    *   В появившемся разделе добавьте группу с именем: `group.com.samvel.ArmenianBible`.
    *   Повторите те же действия для таргета **BibleWidget** (Widget Extension), добавив ту же группу: `group.com.samvel.ArmenianBible`.

4.  **Запустите проект**:
    Выберите симулятор (или реальное устройство с iOS 16+) и запустите таргет `ArmenianBible` (**Cmd + R**).
