# Библиотека цитат для виджетов

`Sources/BibleVerseDatabase+Library.swift` собирается скриптом из `Sources/bible.db` (2026-10-21). Файл не правится вручную.

## Зачем

Длина цитаты теперь зависит от места (`Sources/QuoteTier.swift`, длина считается в знаках на языке виджета):

| Место | Длина |
| --- | --- |
| Экран блокировки | 10–40 (если мало — до 46) |
| Малый виджет | 14–40 (до 55) |
| Средний виджет | 56–90 (45–110) |
| Большой виджет | 101–340 (80–430) |

Старых подборок на средний и большой виджет хватало на ~50 цитат на язык, они быстро повторялись. Теперь к ним добавлено 344 цельных отрывка из Писания (одного стиха или 2–4 подряд), в среднем около 100 цитат на средний и около 280 на большой виджет.

Коротких цитат (экран блокировки, малый виджет) по-прежнему 84 в шести подборках. Целые стихи до 46 знаков одновременно на трёх языках — это в основном родословия и повествовательные обрывки («И сказал Господь Моисею, говоря:»); те, что годятся как цитата, уже есть в подборках. Обрывки стихов и перефразирования в подборки не берутся.

## Что делает скрипт

- склеивает стихи в один отрывок и дочитывает до конца предложения, если стих обрывается на «:», «;» или запятой (до трёх стихов вперёд);
- убирает пометки переводчиков KJV (`{wither: Heb. fade}`), слова-вставки (`{is}`), `{nl}`, заголовки псалмов в `[скобках]`, богослужебное «Слава:»;
- отрезает союз в начале («Ибо», «Итак», «Но», «А», «For», «But», «Որովհետև»…) и ставит заглавную букву; «:» или «;» в конце заменяет точкой;
- пропускает отрывок, если в нём остались скобки, не закрыты кавычки, длины на трёх языках расходятся (признак сдвига нумерации в английской или армянской колонке), или он уже есть в другой подборке (по книге, главе и пересечению стихов);
- в ссылках использует названия книг из старых подборок; номера псалмов по-русски синодальные (на единицу меньше для 10–113 и 117–146);
- армянский текст кладёт в обе редакции: `textHy` — Эчмиадзин (как в базе), `textHyArarat` — Арарат.

Список мест — `REFS`, ручные исключения с причинами — `EXCLUDE` в `build_library.py`.

## Запуск

```bash
python -I Tools/QuoteLibrary/build_library.py report   # что получилось, без записи
python -I Tools/QuoteLibrary/build_library.py write    # записать Sources/BibleVerseDatabase+Library.swift
```

После замены `bible.db` (например, повторной пересборки русской колонки) файл нужно собрать заново.

## Известные ограничения

- Английская и армянская колонки местами сдвинуты (см. `Tools/RussianBible/README.md`); скрипт отсекает отрывки, где длины на трёх языках сильно расходятся, но не все сдвиги так видны.
- Русская колонка — синодальный текст с его знаками препинания; отрезанный союз и заглавная буква — единственные правки текста.
