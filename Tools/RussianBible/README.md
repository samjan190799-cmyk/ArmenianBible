# Русская колонка bible.db

Колонка `text_ru` в `Sources/bible.db` (и в `android_app/app/src/main/assets/bible.db`) пересобрана 2026-10-20 из синодального перевода.

## Что было сломано

- в 841 стихе вместо русского стоял армянский текст (хвосты глав), в 4 — английский;
- русские стихи были сдвинуты или склеены относительно нумерации (Иеремия, Исаия, Иезекииль, Псалмы и др.);
- в тексте попадались пометки вида `(22:1)`, `(4:1)`.

## Источник

`ru_synod.json` из репозитория [thiagobodruk/bible](https://github.com/thiagobodruk/bible/blob/master/json/ru_synod.json): синодальный перевод (общественное достояние), 64 книги, нет Есфири и Даниила. Файл в репозиторий не кладётся.

- размер 6 052 673 байт, SHA-256 `542adc24cc5b5542c0b1879e586832c3c31d0eee64889054b0bd8122cd2908be`
- скачан 2026-10-20

## Как собирается

1. Слова в квадратных скобках (вставки из греческого текста) вырезаются вместе со скобками, в том числе когда вставка переходит из одного стиха в следующий. Так получается та же редакция, что была в базе раньше. Знаки ударения и разделители `||` убираются.
2. Если в главе число стихов в базе и в JSON совпадает, стих N берётся из синодального стиха N (стандартная синодальная нумерация).
3. Остальные главы (около 36) и Псалмы (синодальная нумерация LXX, заголовки отдельными стихами) выравниваются по длине стихов методом Гейла и Черча сразу по двум колонкам базы, армянской и английской: цена группы стихов считается по лучшей из двух, потому что обе колонки местами сдвинуты. Там, где стихи в источнике склеены, второй стих получает пометку «(см. предыдущий стих)»: таких строк 43.
4. Заголовки псалмов ставятся в квадратных скобках перед первым стихом, как в английской колонке.
5. Есфирь и Даниил в JSON нет: их прежний текст очищен от пометок, армянские заглушки убраны тем же выравниванием.
6. Поисковый индекс `verses_fts` пересобирается, база сжимается (`vacuum`).

Колонки `text_hy`, `text_en`, `text_hy_ararat`, идентификаторы и схема не меняются.

## Запуск

```bash
python -I Tools/RussianBible/ru_rebuild.py report
python -I Tools/RussianBible/ru_rebuild.py apply /tmp/bible_new.db
```

## Известные ограничения

- В английской и армянской колонках тоже есть сдвиги (например, Матфея 22 в английской, Иоанна 8 в армянской, где нет 8:1–11); они не исправлялись.
- Android-приложение копирует базу из ассетов только при первой установке (`BibleDatabaseHelper.copyDatabaseIfNeeded`), поэтому на уже установленных телефонах исправление само не появится.
