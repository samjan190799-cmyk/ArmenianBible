# Подлинный текст «Մատեան Ողբերգութեան» (Книга скорбных песнопений)

`Sources/narek_original_hy.json` (2026-10-21) — армянский оригинал книги, 95 глав, 448 строф, 8 756 строк, около 395 тысяч знаков.

## Источник

Страница [«Մատեան Ողբերգութեան»](https://hy.wikisource.org/wiki/%D5%84%D5%A1%D5%BF%D5%A5%D5%A1%D5%B6_%D5%88%D5%B2%D5%A2%D5%A5%D6%80%D5%A3%D5%B8%D6%82%D5%A9%D5%A5%D5%A1%D5%B6) на hy.wikisource.org (грабар, автор Գրիգոր Նարեկացի). Ссылку дал владелец приложения. Правка №394708 от 2026-09-06; номер правки и контрольная сумма записаны в самом файле (`source`). Какое печатное издание взято за основу, на странице не сказано.

Книга написана в X веке и свободна; Wikisource размещает только свободные тексты. Переводы на русский и английский защищены авторским правом переводчиков и в приложение **не входят**: в приложении этот текст показывается всем только на армянском, с пометкой.

## Как собирается

```bash
python -I Tools/NarekOriginal/build_original.py report [файл.wiki]   # проверка без записи
python -I Tools/NarekOriginal/build_original.py write [файл.wiki]    # записать Sources/narek_original_hy.json
```

Без пути скрипт скачивает викитекст через API MediaWiki (нужен заголовок User-Agent, иначе Викимедиа отвечает 403).

В источнике глава — это заголовок `== Բան Ա ==`, внутри `<poem>`: заголовок прописными буквами (одна-две строки), затем строфы; каждая строфа начинается строкой с армянской цифрой.

## Что исправлено в тексте (следы набора, не слова автора)

- «`` ` ``» в конце строк → армянский знак «՝»;
- «,-» в конце строки → «,»;
- буква «þ» (10 мест: Բան ԾԲ, ՀԲ, ՀԵ, ՀԷ, ՂԲ, ՂԳ) — след кавычки: убрана, перед прописной буквой остался пробел;
- «_» → пробел, лишние «\\» и «+» убраны, неразрывный пробел → пробел;
- заголовки глав из прописных переведены в обычный регистр, имена («Աստուած», «Միւռոն») с заглавной;
- в заголовке 87-й главы в источнике опечатка «Բան ԶԷ»: подпись исправлена на «Բան ՁԷ».

## Что оставлено как в источнике

- Знаки « . », « : », «,» не меняются на «։».
- В главах 66, 72, 75, 77, 78 нумерация строф нарушена (пропущены или повторены цифры), в главах 84 и 89 цифр нет совсем. Это ошибки набора на Wikisource; цифры не «исправляются», потому что неизвестно, потеряна цифра или строфа.
- Орфография классическая (грабар), как в источнике.

## Известные ограничения

- Заголовок 85 глав начинается с редакторской строки «Վերստին յաւելուած կրկին հեծութեան…» (так в источнике).
- Сверка с печатным изданием не делалась: ошибки набора на Wikisource возможны.

**Права.** Это работы XX века. Если срок защиты в Армении — жизнь автора + 70 лет (так я понимаю закон, юридической проверкой это не является), то перевод Хераняна, умершего в 1970 году, защищён до 2040 года; про Геворкяна ничего не известно. Автор оригинала (951–1003) на странице автора помечен как общественное достояние, а переводы такой пометки не имеют. Поэтому **текст переводов в приложение не копируется**: в чтении главы есть кнопка со ссылкой на нужную главу на Wikisource (`NarekModernArmenian` в `Sources/NarekOriginal.swift`). Якоря проверены по `action=parse&prop=sections` для всех глав; в заголовке 87-й главы на обеих страницах опечатка «Բան ԶԷ».

Чтобы показывать современный армянский прямо в приложении, нужно либо разрешение правообладателей (наследников, издателя), либо перевод со свободной лицензией.
