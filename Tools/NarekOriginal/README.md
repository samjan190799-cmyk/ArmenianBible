## Как собирается

```bash
python -I Tools/NarekOriginal/build_original.py report [файл.wiki]   # проверка без записи
python -I Tools/NarekOriginal/build_original.py write [файл.wiki]    # записать Sources/narek_original_hy.json
```

Без пути скрипт скачивает викитекст через API MediaWiki (нужен заголовок User-Agent, иначе Викимедиа отвечает 403).

В источнике глава — это заголовок `== Բան Ա ==`, внутри `<poem>`: заголовок прописными буквами (одна-две строки), затем строфы; каждая строфа начинается строкой с армянской цифрой.

## Что исправлено в тексте (следы набора, не слова автора)

- «`` ` ``» в конце строк → армянский знак «՝»;
- «,-» в конце строки → «,»;
- буква «þ» (10 мест: Բան ԾԲ, ՀԲ, ՀԵ, ՀԷ, ՂԲ, ՂԳ) — след кавычки: убрана, перед прописной буквой остался пробел;
- «_» → пробел, лишние «\\» и «+» убраны, неразрывный пробел → пробел;
- заголовки глав из прописных переведены в обычный регистр, имена («Աստուած», «Միւռոն») с заглавной;
- в заголовке 87-й главы в источнике опечатка «Բան ԶԷ»: подпись исправлена на «Բան ՁԷ».
