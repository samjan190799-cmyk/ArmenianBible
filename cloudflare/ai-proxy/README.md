# Luys AI: посредник между приложением и ИИ

Бесплатный Worker на Cloudflare. Человеку не нужен свой ключ ИИ: приложение шлёт вопрос сюда, а ключ лежит только на сервере.
Подписчику отвечают по подписке (до `DAILY_LIMIT` в сутки), без подписки по малому бесплатному лимиту (см. «Бесплатные вопросы»).

## Как это работает

1. Подписчик задаёт вопрос. Приложение отправляет `POST /v1/generate` с вопросом и подписанным Apple подтверждением подписки (JWS из StoreKit 2).
2. Worker проверяет подпись Apple. Цепочка сертификатов должна заканчиваться корнем **Apple Root CA G3** (отпечаток закреплён в `src/apple.js`) и иметь расширения Apple для чеков App Store. Вторая проверка важна: промежуточный сертификат Apple выдаёт сертификаты и обычным разработчикам, без неё кто угодно мог бы подписать «покупку» сам.
3. Проверяет, что подписка наша (`bundleId`, `productId`), не отозвана и не истекла.
4. Считает дневной лимит подписчика (по `originalTransactionId`) и общий потолок сервиса: оба в Durable Objects.
5. Идёт к Gemini с ключом из секретов Worker и возвращает ответ. Если первая модель из `GEMINI_MODELS` закрыта, не ответила вовремя (25 секунд) или вернула пустой ответ, пробуется следующая; не принят ключ или исчерпана квота Google — перебор останавливается. Если ИИ не ответил, вопрос человеку не засчитывается.

Тексты вопросов и ответов нигде не записываются.

## Бесплатные вопросы

Без подписки приложение шлёт `installId` (случайный UUID, создаётся на устройстве) вместо подтверждения покупки. Сервер берёт один вопрос из каждого счётчика по порядку и возвращает все, если ИИ не ответил или любой отказал:

1. по сети (`FREE_NET_DAILY_LIMIT`, в Durable Object хранится хэш адреса с солью дня, не сам адрес): против бесконечных переустановок;
2. по установке (`FREE_DAILY_LIMIT`): в приложении 3 вопроса в сутки по местному времени, здесь с запасом на границу суток по UTC;
3. по всем бесплатным вместе (`FREE_GLOBAL_DAILY_LIMIT`): потолок расходов на бесплатный путь; его исчерпание не мешает подписчикам;
4. общий потолок сервиса (`GLOBAL_DAILY_LIMIT`).

`ALLOW_FREE = "false"` выключает бесплатный путь целиком (ответ 403 `free_disabled`). Худший суточный расход на бесплатных не больше `FREE_GLOBAL_DAILY_LIMIT` ответов.
Слабое место: номер установки не привязан к устройству Apple (нет App Attest), поэтому тот, кто умеет подделывать запросы, упирается только в сетевой и общий потолки.

## Что бесплатно, а что нет

- Бесплатно: сам Worker (на бесплатном тарифе порядка 100 тысяч запросов в сутки) и счётчики. Банковская карта для этого не нужна.
- Не бесплатно: ответы ИИ. Для личных вопросов людей нужен **платный** ключ Gemini: данные бесплатного уровня Google может использовать для улучшения своих продуктов. Расход ограничивают `DAILY_LIMIT` (на человека) и `GLOBAL_DAILY_LIMIT` (на весь сервис) в `wrangler.toml`.

## Развернуть (один раз, около 15 минут)

Нужен Node (у вас уже стоит).

1. Создайте бесплатный аккаунт на https://dash.cloudflare.com (почта и пароль).
2. В терминале:
   ```bash
   cd cloudflare/ai-proxy
   npm install
   npx wrangler login
   npx wrangler deploy
   ```
   В конце команда напишет адрес вида `https://luys-ai.<ваш-поддомен>.workers.dev`. При первом запуске Cloudflare попросит придумать поддомен.
3. Выпустите ключ Gemini в Google AI Studio (https://aistudio.google.com/apikey), включите платный уровень, и положите ключ в секреты (он спросит значение, в историю терминала оно не попадёт):
   ```bash
   npx wrangler secret put GEMINI_API_KEY
   ```
4. Проверьте:
   ```bash
   curl https://luys-ai.<ваш-поддомен>.workers.dev/health
   ```
   Должно быть `{"ok":true,"service":"luys-ai","configured":true,...}`.
5. Адрес из шага 2 впишите в приложение: `Sources/AIProxy.swift`, константа `baseURL`. Пока она пустая, приложение работает как раньше (только со своим ключом).

Обновить Worker позже: `npx wrangler deploy`. Сменить ключ: `npx wrangler secret put GEMINI_API_KEY`.

В Windows PowerShell команды `npm` и `npx` могут не запускаться (защита выполнения скриптов): пишите `npm.cmd` и `npx.cmd`, а вместо `curl` пишите `curl.exe`. Имя секрета (`GEMINI_API_KEY`) пишется в команде, а сам ключ вводится позже на вопрос `Enter a secret value`; ключ в команде и в чате не показывайте.

Выпущено: `https://luys-ai.samjan190799.workers.dev` (аккаунт Cloudflare на бесплатном тарифе, поддомен `samjan190799.workers.dev`).

### Автоматический выпуск (по желанию)

Если в секреты репозитория GitHub добавить `CLOUDFLARE_API_TOKEN` (шаблон «Edit Cloudflare Workers») и `CLOUDFLARE_ACCOUNT_ID`, то после слияния в `main` Worker будет выпускаться сам (`.github/workflows/ai-proxy.yml`). Тесты запускаются на каждый пуш в `cloudflare/ai-proxy/`.

## Настройки (`wrangler.toml`)

| Переменная | Что делает |
| --- | --- |
| `DAILY_LIMIT` | запросов к ИИ в сутки (по UTC) на одного подписчика, по умолчанию 30 |
| `ALLOW_FREE` | `"false"` выключает бесплатные вопросы |
| `FREE_DAILY_LIMIT` | бесплатных вопросов в сутки на установку, по умолчанию 5 |
| `FREE_NET_DAILY_LIMIT` | бесплатных вопросов в сутки с одной сети, по умолчанию 15 |
| `FREE_GLOBAL_DAILY_LIMIT` | бесплатных вопросов в сутки на всех вместе, по умолчанию 300 |
| `GLOBAL_DAILY_LIMIT` | запросов в сутки на весь сервис: потолок расходов, по умолчанию 3000 |
| `ALLOW_SANDBOX` | `true`: подписки из TestFlight и проверяющих Apple приходят как Sandbox. Оставляйте `true` и после выпуска в App Store: иначе ИИ не заработает на проверке следующих версий |
| `GEMINI_MODELS` | модели Gemini для вопросов через сервер, по порядку: если первая недоступна, пробуется следующая. По умолчанию `gemini-3.5-flash-lite,gemini-3.6-flash,gemini-2.5-flash-lite` |
| `AI_MODEL_CATALOG` | необязательно: JSON `{"gemini":[...],"openai":[...],"claude":[...]}`, заменяет список для кнопки «Обновить модели» (см. ниже) |
| `PRODUCT_IDS`, `BUNDLE_ID` | какие подписки и какое приложение считаются нашими |

## Задачи ИИ и отдельные ключи

Приложение указывает в запросе, для чего он (поле `task`): `chat` (чат «Духовный Проводник»), `quiz` (вопросы викторины),
`consolation` («Нарек утешает»), `explain` (толкование стиха), `verse` (подбор стиха). Всё остальное и запросы без поля идут как `general`.
Для каждой задачи можно задать отдельно (всё необязательно):

| Что | Как задать | Зачем |
|---|---|---|
| Свой ключ Gemini | `npx wrangler secret put GEMINI_API_KEY_CHAT` (и `_QUIZ`, `_CONSOLATION`, `_EXPLAIN`, `_VERSE`) | расход и квота Google считаются отдельно, ключ можно заменить по задаче |
| Свои модели | переменная `GEMINI_MODELS_CHAT` (список через запятую) | например, мощнее для чата и дешевле для викторины |
| Суточный потолок | переменная `TASK_DAILY_LIMIT_QUIZ` (запросов в сутки по UTC на всех вместе) | чтобы одна задача не съела общий бюджет; сверх потолка ответ 503 `busy`, вопрос человеку не засчитывается |

Что не задано, берётся общее: `GEMINI_API_KEY` и `GEMINI_MODELS` работают как раньше, потолка у задачи нет. Общий ключ остаётся обязательным
(на нём работают `general` и все задачи без своего ключа). Имя задачи из запроса в настройки напрямую не подставляется: допустимы только пять имён из списка (src/tasks.js).

## Список моделей и кнопка «Обновить модели»

`GET /v1/models` отдаёт открытый список актуальных моделей Google, OpenAI и Anthropic (без ключей и без данных людей):

```json
{"version":1,"updated":"2026-11-05","gemini":["gemini-3.5-flash-lite","gemini-3.6-flash","..."],"openai":["gpt-6-luna","..."],"claude":["claude-haiku-5-5","..."]}
```

Фоновая проверка раз в 12 часов берёт список отсюда (кнопки «Обновить модели» в настройках приложения больше нет: ИИ работает только через этот сервер, личные ключи и выбор провайдера убраны), проверяют идентификаторы и сохраняют у себя. Так новые модели доходят до людей без выпуска версии в App Store. Нет сети или сервер молчит: приложение работает с последним сохранённым списком, а если его не было, со встроенным в `Sources/AIModelRegistry.swift`.

Порядок в списке важен: от быстрой и недорогой модели (ею отвечают по умолчанию) к более мощным запасным, приложение пробует их по очереди.

**Как обновить список.** Откройте `src/models.js`, поправьте массивы и дату, затем выпустите Worker (`npx wrangler deploy`): пока Worker не выпущен заново, приложения продолжают получать прежний список. Без правки кода список можно подменить переменной `AI_MODEL_CATALOG` в настройках Worker. Скрипт `auto_discover_ai_models.py --apply` (еженедельный воркфлоу `auto-update-ai-models.yml`) умеет сам пересобрать `src/models.js` по результатам проверки моделей ключами владельца, но выпуск Worker остаётся отдельным шагом: пуш от имени `GITHUB_TOKEN` не запускает `ai-proxy.yml`.

Сверять модели нужно с официальными страницами провайдеров: [Google](https://ai.google.dev/gemini-api/docs/models), [OpenAI](https://developers.openai.com/api/docs/models) и [Anthropic](https://platform.claude.com/docs/en/about-claude/model-deprecations). Идентификатор в списке попадает в адрес запроса, поэтому Worker и приложение пропускают только латиницу, цифры, точку, дефис и подчёркивание, а начало имени должно подходить провайдеру (`gemini-`, `gpt-` или `o` с цифрой, `claude-`).

## Ответы сервера

| Код | Ответ | Что значит |
| --- | --- | --- |
| 200 | `{text, model, remaining}` | всё хорошо; `remaining` сколько вопросов осталось сегодня |
| 401 | `unauthorized`, `reason` | подпись Apple не прошла (`bad_format`, `bad_header`, `bad_chain`, `bad_root`, `bad_leaf`, `bad_signature`) |
| 403 | `no_subscription`, `reason` | подписка не подходит (`expired`, `revoked`, `bundle`, `product`, `sandbox`, `environment`, `no_id`) или бесплатный путь выключен (`free_disabled`) |
| 429 | `quota` | дневной лимит человека (или его сети) исчерпан; в ответе `tier`: `premium` или `free` |
| 503 | `busy` / `not_configured` | общий потолок сервиса или нет ключа в секретах |
| 502 | `ai_failed` | ИИ не ответил; вопрос не списан |

## Что не покрыто

- Ранние покупатели платной версии и пожизненный доступ не имеют подписки в StoreKit: их вопросы идут как бесплатные (со своим лимитом), либо они вводят свой ключ.
- Проверка идёт по подписанному подтверждению покупки, без запроса в App Store Server API. Если кто-то отдаст своё подтверждение другому, они разделят один дневной лимит.
